About

What I build

I'm a full-stack AI engineer focused on multi-agent LLM systems and backend infrastructure. My work spans building LangGraph-orchestrated agent networks, async job pipelines, RAG retrieval systems, and secure REST APIs.

Most of my projects combine a TypeScript operational layer (auth, routing, persistence, integrations) with a Python reasoning layer (agent graphs, LLM tool-calling, semantic retrieval) — a deliberate separation that makes systems auditable, debuggable, and production-safe.

I care about measurable outcomes: sub-2s latency, documented cost reductions, and reliability patterns like timeout guards, schema-validated messaging, and fallback paths. I also have a research side — AdaptSRNet is my deep learning work in image steganalysis.

Research

Deep learning work

AdaptSRNet — Adaptive Spatial Rich Model Network for Image Steganalysis

A lightweight attention-based CNN architecture for detecting hidden information (steganography) embedded in digital images via the WOW algorithm — one of the hardest detection targets because it modifies only a handful of pixels.

The core contribution is replacing fixed SRM filter banks with learnable filters that are optimized end-to-end, enabling the network to discover more discriminative residual patterns than handcrafted preprocessing allows.

PyTorch Python BOSSBase dataset FP16 mixed precision ~1–2M params

Architecture Contributions

Learnable SRM layer — end-to-end filter optimization replacing fixed handcrafted residuals
Multi-scale extraction — 4 parallel branches (1×1, 3×3, 5×5, pooling) with SE attention fusion
4-stage residual progression: 128 → 192 → 256 → 384 channels
Hybrid SE + CBAM attention (channel + spatial) for stego-artifact focus
Dual global pooling (avg + max → 768-D) for richer feature representation
